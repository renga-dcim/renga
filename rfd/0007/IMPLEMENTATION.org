#+TITLE: RFD 0007 implementation checklist

Implements [[file:README.adoc][RFD 7: Layer 2 topology and VLANs]].

* Phase 1: VLAN namespace foundations

- [X] Add resource envelopes and typed projections for VLAN groups and VLANs,
  including global operation without RFD 5 placement data.
- [X] Add non-overlapping valid VID ranges, bounded VLAN IDs, null-safe global
  namespace uniqueness, group-local uniqueness, and transactionally safe range
  changes under a shared group-level lock or equivalent deferred invariant.
- [X] Add optional typed site/location group scope after RFD 5, without generic
  cross-domain foreign keys.

* Phase 2: Interface membership and evidence

- [ ] Add separate desired and reconciled current tagged/untagged interface
  membership, layer-local effective untagged VLAN rules, interface mode
  validation, and tenant-safe constraints.
- [ ] Add source-local VLAN mapping and observation-linked membership evidence
  with complete-versus-partial snapshot and stale semantics.
- [ ] Extend logical interface relationship evidence without conflating host
  stacking, Layer 2 adjacency, and physical cabling.

* Phase 3: Neighbor discovery and adjacency

- [ ] Add LLDP/CDP evidence, stable remote endpoint matching, expiry, reciprocal
  confidence, unresolved endpoints, canonical adjacency, and findings.

* Phase 4: Cable intent and reconciliation

- [ ] Add separate cable plans, attributed assertions, and reconciled current
  direct cables with endpoint compatibility, current-only single active
  termination, authorization, and change history.
- [ ] Ensure neighbor evidence can propose or validate but never automatically
  create, delete, or move a cable.

* Phase 5: Cross-domain integration and product surfaces

- [ ] Add optional tenant-safe prefix/VLAN relationships without making VLANs a
  prerequisite for IPAM.
- [ ] Add authenticated organization-scoped VLAN, topology, cable, and finding
  LiveViews in the existing `live_session :require_authenticated_user` router
  block.

* Phase 6: Verification and completion

- [ ] Add tenant, namespace, VLAN/range race, membership concurrency, evidence,
  matching, cable, authorization, and LiveView tests.
- [ ] Run `make check-rfds`, focused topology tests, and `mix precommit` before
  marking the proposal implemented.
