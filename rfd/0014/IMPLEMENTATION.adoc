= RFD 0014 implementation checklist

Implements link:README.adoc[RFD 14: VM lifecycle operations].

* [ ] Add desired power state on VM envelopes and the power-state drift finding.
* [ ] Add `vm.power@1` actions with stable operation identity and before/after
  state; distinguish convergent actions from non-idempotent reboot/reset.
* [ ] Extend RFD 9 lease-loss handling to record uncertain reboot/reset outcomes
  without automatic re-execution. Test crashes before/after the libvirt effect,
  lost completion, and duplicate delivery; do not equate running state with
  proof of a reboot/reset outcome.
* [ ] Require approved VM/provider/domain bindings and revalidate them at
  preview, dispatch, and execution. Test forged placement, retained inactive
  definitions, migration, ambiguous/stale evidence, and changes after approval.
* [ ] Add organization enablement and expiring VM operator grants, with a reason
  and confirmation for `force_off` and `reset`.
* [ ] Add optional two-operator approval for destructive actions.
* [ ] Add the operation preview and power controls on the VM page.
