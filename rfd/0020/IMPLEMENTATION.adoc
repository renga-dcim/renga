= RFD 0020 implementation checklist

Implements link:README.adoc[RFD 20: Organization export and import].

* [ ] Define the archive format: `manifest.json` with checksums and counts, and
  a documented schema per record type and format version.
* [ ] Add the `organization.export` permission, held only by `owner`.
* [ ] Export a dependency-closed current snapshot from one repeatable-read
  transaction, with optional history and additional raw observations; test that
  concurrent intake does not produce an inconsistent archive.
* [ ] Serve the archive through a revocable, expiring download that rechecks
  current authorization; delete it after seven days and audit every action.
* [ ] Exclude every credential and deployment setting; test that no password
  hash, passkey, token, key hash, job credential, or pending approval appears in
  an archive.
* [ ] Validate a whole archive before writing: reject unsafe paths and links,
  bound expansion and record sizes, enforce tenant-closed references, and
  report every problem that can be safely collected.
* [ ] Recheck authorization, emptiness, collisions, and destination constraints
  while importing atomically without concurrent target writes; perform external
  effects only after commit.
* [ ] Preserve organization-owned IDs unless importing a copy, and re-allocate
  every revision and embedded version in source order while bounding the effect
  on other organizations' revision writes.
* [ ] Export source-scoped principals and preserve the authority, status, and
  validity of memberships, team memberships, assignments, and actor references.
* [ ] Restore only active manual access through verified invitations; keep
  externally managed, expired, disabled, and revoked access inactive until its
  destination authority freshly establishes it.
* [ ] Keep imported actor attribution distinct from destination accounts and
  keep unclaimed personal records private until their owner is safely linked.
* [ ] Import installation keys as pending, bindings unapproved, and terminal and
  VM grants disabled regardless of invitation acceptance.
* [ ] Import jobs and events as inert history that can never lease, retry, gain
  approval, or execute; require a new destination job for new work.
* [ ] Import portable organization policy without overriding destination locks,
  and require owner confirmation before weakening security settings.
* [ ] Add `renga export` and `renga import` release commands.
* [ ] Add converters from each previous archive format version, and refuse
  archives from newer releases.
* [ ] Round-trip fixtures cover externally managed access, a queued job,
  dependency-closed evidence without optional data, a former actor, and an
  unclaimed private saved view.
