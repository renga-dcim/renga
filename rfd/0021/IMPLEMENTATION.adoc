= RFD 0021 implementation checklist

Implements link:README.adoc[RFD 21: Per-organization limits].

* [ ] Stop and drain every resource writer for the cutover, then key the
  resource revision lock by organization in its own lock namespace. Test that
  writes in two organizations do not wait on each other, revision commit order
  holds within each organization, and old and new allocators cannot overlap.
* [ ] Bound credential lookup before organization admission, split contact
  recording from authentication, and coalesce authenticated contact writes in
  a bounded recorder. Test that rejected floods cannot consume connections
  reserved for another organization.
* [ ] Add separate per-organization and per-installation capacity for bulk
  observations and lease maintenance. Reserve capacity for check-ins and
  already-leased job reports, and backpressure new leases before using it.
* [ ] Return `429` with `Retry-After` and teach the agent to treat it as a
  retry-not-before deadline without exceeding its delivery budget; test
  observation retry and RFD 9 lease-loss behavior.
* [ ] Add an intake size limit and hold each per-organization concurrency
  admission through acceptance and reconciliation on each node.
* [ ] Add per-user and per-organization HTTP and LiveView event/navigation
  limits with a retryable LiveView notice, and move the job creation limit into
  the same settings.
* [ ] Set a baseline `statement_timeout` for every application connection,
  transaction-local overrides for approved background queries, and wall-clock
  budgets for their workers. Test standalone reads as well as transactions.
* [ ] Add a persistent fair organization scheduler for job lease/deadline
  sweeps and history purge: one bounded batch per ready organization per round,
  with lease processing latency kept inside its expiry budget.
* [ ] Make neighbor expiry resumable by staging a complete generation at a
  fixed evidence watermark. Include adjacency, neighbor-finding, and cable
  reconciliation; publish only after every batch completes and the evidence
  version still matches. Test restart, concurrent evidence, timeout, and that
  unvisited rows never cause deletion or finding resolution.
* [ ] Add an organization quota ledger with atomic, idempotent reservation and
  mutation across nodes. Implement the accounting table, 80% findings,
  below-current-use behavior, and crash-safe expiry for byte reservations.
* [ ] Reserve 50 MiB before authorizing a terminal session and the declared
  maximum before starting an export. Convert reserved bytes to retained bytes
  as they are written, release only unused capacity, and never start work whose
  required audit or archive storage cannot be reserved.
* [ ] On resource exhaustion, accept the immutable observation, record a
  structured `quota_deferred` failed reconciliation, and enqueue one durable
  retry item. Retry fairly after capacity changes and periodically across
  restarts through the explicit retry path. Test fill, accept, restart, free,
  and reconcile without agent retransmission, including a newer observation
  arriving while the older one waits.
* [ ] Read defaults from the environment, add `renga limits set` for
  per-organization overrides, and show usage to owners read-only.
* [ ] Emit per-organization telemetry for intake, database time, and rejected
  requests.
