= RFD 0016 implementation checklist

Implements link:README.adoc[RFD 16: SCIM provisioning].

* [ ] Add SCIM connections per organization, created by owners, naming an
  eligible `oidc` provider and a provider-declared stable, unique correlation
  claim; make both immutable, scope organization providers to their own
  organization when RFD 15 defines them, and refuse an organization that
  already has an RFD 15 claim mapping. Also refuse adding a claim mapping to an
  organization that already has a SCIM connection.
* [ ] Add connection bearer tokens stored as hashes, revealed once, with two
  active tokens for rotation and immediate revocation; redact them from logs,
  diagnostics, and audits, and test that tokens only reach `/scim/v2` and only
  their own organization.
* [ ] Serve `ServiceProviderConfig`, `ResourceTypes`, and `Schemas`, advertise
  only their defined capabilities, and return `501` for `/Me`.
* [ ] Add `scim_users`, `scim_groups`, and group memberships with
  per-connection uniqueness on user `userName` and `externalId` and an optional
  binding from a user entry to a specific RFD 15 identity.
* [ ] Implement `Users` and `Groups` create, read, replace, patch, delete, and
  list with `eq` filters and bounded pagination; implement the documented
  omitted, null, empty, and explicit-value semantics and return SCIM errors.
* [ ] Accept Okta and Microsoft Entra ID PATCH variants and test them against
  recorded request fixtures, including Entra's title-case `"True"` and
  `"False"` strings. Verify that `"False"` removes the SCIM grant and refreshes
  organization-scoped live authorization while preserving manual access and
  unrelated organizations. Accept and discard create-time passwords without
  persisting, logging, auditing, or returning them, and reject password changes.
* [ ] Link directory entries at provider sign-in and reauthentication by the
  exact nonempty correlation claim; reject missing, malformed, ambiguous, and
  unsafe claim values and reassignment, clear bindings and grants when their
  identity source or `externalId` changes, and allow provider sign-up for active
  entries. Keep RFD 15's email collision refusal and test that SCIM never
  changes account email, name, credentials, or other memberships.
* [ ] Grant memberships from the default role and group mappings as
  source-bound grants keyed by stable, connection-scoped group IDs, with manual
  membership precedence. Reconcile after every source mutation, including
  default and mapping changes, partial group removal, identity unlinking, and
  provider or connection disablement; test upgrades, downgrades, and removal.
* [ ] Enforce reconciled authorization on every HTTP request and immediately on
  connected LiveViews, Channels, terminals, and later leased operations.
  Redirect only after effective membership loss, preserve manual access and
  unrelated organizations, and never expire a provider session or let provider
  reauthentication recreate absent SCIM authority.
* [ ] Show directory entries, linked or not, in the organization member list.
* [ ] Bound request size and rate limit per connection.
* [ ] Record audit entries for SCIM changes and connection administration.
